# Changelog

## 1.0.0 (open, not posted)

Milestone 1 - foundation and discovery:
- An editor window drawn through Apocrypha Menu Framework (or SKSE Menu Framework 3) over the RaceSex Menu, shown when
  RaceMenu opens; the switch key (F4) or a button switches between it and RaceMenu's own interface.
- Reads what RaceMenu's movie holds - every list with its path, size and entries, and RaceMenu's Scaleform functions -
  and shows the lists in a rail with their entries. Read-only in this milestone.
- Settings page inside the menu framework (switches, precise sliders, Save / Reload / Restore defaults), INI with every
  setting, eleven languages.
- DevBench tool `likeness.control`: state, probe, list, plugins, show, hide, switch, reload.
